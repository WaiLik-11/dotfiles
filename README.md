# 🧠 Wai Lik's Dotfiles

My personal dev environment for setting up Zsh, Git, and web-dev environment on any new machine (via WSL, Linux, or Mac).

## Features

- Zsh + Oh My Zsh + Awesomepanda Theme
- Git & GitHub Configuration
- Auto symlink dotfiles

## Setup
### One-line install (new machine)

```bash
curl -fsSL https://raw.githubusercontent.com/WaiLik-11/dotfiles/main/bootstrap.sh | bash
